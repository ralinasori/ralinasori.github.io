Privacy policy: rclone-backup

Last updated: 2026-10-19

rclone-backup is a personal tool run only by its developer on their own computers.

  • What it accesses: files in the developer's own Google Drive, only to upload backup copies and to check that they arrived intact.
  • Where data goes: directly between the developer's computer and Google Drive. No data is sent to the developer's servers or to any third party, because there are none.
  • What is stored: an access token is kept in a private configuration file on the developer's own computer. Nothing else is collected.
  • Sharing or selling data: never. No one other than the developer uses this app.
  • Google API data use: the app's use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.
  • Contact: open an issue or message github.com/ralinasori.
